# CampusMarket

Semester project for Software Engineering

CampusMarket is a database-driven e-commerce web application designed for university students to browse, filter, view, and order useful campus products.

## Features

- Product catalog
- Product search and category filtering
- Dynamic product gallery
- Responsive design
- Product ordering and running total
- Form validation
- Animated success feedback
- Accessible image alt text
- Mobile-friendly interface
